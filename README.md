# 자동차 경주
## 기능 요구 사항
- n 대의 자동차는 전진 또는 정지 가능
- 각 자동차에 이름 부여 가능
- 전진하는 자동차를 출력할 때 자동차 이름도 같이 출력하기
- 자동차 이름은 , 로 구분
- 자동차 이름은 5자 이하만 가능
- 사용자는 몇 번의 이동을 할 건지 입력 가능
- 전진 조건은 0에서 9 사이 랜덤 값에서 4 이상일 경우
- 우승자가 여러 명이면 , 로 구분
- 잘못 입력하면 "[Error]" 메세지와 함께 종료

## 입출력 요구 사항
### 입력
- 자동차 이름

`aaa,bbb,ccc`
- 시도 횟수

`5`

### 출력
- 차수별 실행 결과
```
aaa : --
bbb : ----
ccc: -
```
- 우승자
`최종 우승자 : aaa, bbb`

### 결과 예시
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
< 자동차 이름 입력하기 >
시도할 횟수는 몇 회인가요?
< 횟수 숫자 입력하기 >

실행 결과
< 실행 결과 나옴 >

최종 우승자 : < 자동차 이름 >
```
